# Arklum v3.0.0

> The biggest update yet — Arklum has been fully rebuilt in JavaScript, with a reworked interface, deeper bot customization and a real plugin platform.

[toc]

## The JavaScript rebuild
[card title="Rebuilt from the ground up" icon="⚡"]
Arklum is now **100% JavaScript**. The entire Python codebase was translated and reworked into a modern Node.js platform:
- Faster startup and real-time dashboard updates
- Encrypted token vault with multi-bot support
- A stable plugin platform with its own marketplace
- Live system monitoring and logs, right in the dashboard
[/card]

## A reworked interface
[card title="Designed to feel premium" icon="🎨"]
- **Glassmorphism** across every page, on desktop and mobile
- **Custom themes** — colors, glass blur, fonts, backgrounds, loading screen, sidebar logo and chat corners, all from Settings → Appearance
- **Personalization** — fonts, UI density, border radius, shadows, animation speed and easing
- **Mouse effects** — 3D tilt, glass aperture, magnetic buttons, ink ripple, dynamic shadows and particles, with automatic low-performance mode
- **Notification center** for mentions, DMs and replies
[/card]

## Chat & Voice
[cols]
[col]
**Chat** [badge color=#00d4aa]REWORKED[/badge]
- Grouped messages, date dividers and a **NEW** divider for unread history
- **Infinite scroll** into older history + jump-to-present pill
- **Unread badges** on channels
- Swipe right to **reply**, further to **edit**, long-press for quick reactions
- Autocomplete for **@members**, **#channels**, **:emojis**
- **Syntax-highlighted** code blocks and file previews with language badge and line count
- Automatic image compression, video transcoding, inline audio
- Invite links become **live invite cards**
- Rich **mini-profiles** with banners, badges, nameplates and roles
[col]
**Voice** [badge color=#00d4aa]REWORKED[/badge]
- **Voice text chat** opens directly from any voice channel
- Floating **voice pill** with live dot, channel name and call timer
- Member panel with **speaking indicators**
- Draggable pill and one-tap leave
[/cols]

## Server management

## Plugins & Marketplace
[card title="Extend Arklum" icon="🧩"]

[note type="info"]
